AMLCR extends multi-level container reuse for serverless computing. Instead of starting a function only in a warm container with an identical setup, it can reuse a container that shares the same operating system, language runtime or part of the package set. It decides which warm container to reuse, whether to keep a container after it finishes, and when to adapt to a changing workload. This repository holds the simulator, trained weights, raw results and figure scripts for the manuscript “Adaptive Multi-Level Container Reuse for Cold-Start Latency and Memory Optimization in Serverless Computing”.
